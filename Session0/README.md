# Session0 — ハンズオン環境のセットアップ

**Session1を始める前に、必ずこの手順を完了してください。**

詳細はPDF資料 [ハンズオン環境の使い方.pdf](ハンズオン環境の使い方.pdf) を参照してください。

---

## 手順1 — 指定URLをブラウザで開く

以下のURLをブラウザで開いてください。

```
https://catalog.us-east-1.prod.workshops.aws/join?access-code=f301-06eddc-8f
```

---

## 手順2 — ハンズオン環境にサインイン

1. サインイン方法の選択画面で **「Email One-Time Password (OTP)」** を選択する
2. 自分のメールアドレスを入力し「Send passcode」をクリック
3. メールで届いた9桁のパスコードを入力し「Sign in」をクリック

---

## 手順3 — AWS マネジメントコンソールに接続

1. サインイン後の画面で左メニュー「AWS account access」の **「Open AWS console (ap-northeast-1)」** をクリック
2. AWS マネジメントコンソールが表示されたら準備完了

---

## 注意事項

- 参加者それぞれに個別のAWSアカウントが発行されます
- **この環境はイベント終了後に削除されます**。保存したいファイルは必ずPCにダウンロードしてください
- AWSサポートへの問い合わせやサービス上限緩和申請は行わないでください
- ハンズオン以外の目的で利用しないでください
