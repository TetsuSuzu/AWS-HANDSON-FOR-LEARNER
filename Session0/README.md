# Session0 — ハンズオン環境のセットアップ

**Session1を始める前に、必ずこの手順を完了してください。**

詳細はPDF資料 [ハンズオン環境の使い方.pdf](ハンズオン環境の使い方.pdf) を参照してください。

---

## 手順1 — 指定URLをブラウザで開く

以下のURLをブラウザで開いてください。

```
https://catalog.us-east-1.prod.workshops.aws/join?access-code=f301-06eddc-8f
```

---

## 手順2 — ハンズオン環境にサインイン

1. サインイン方法の選択画面で **「Email One-Time Password (OTP)」** を選択する
2. 自分のメールアドレスを入力し「Send passcode」をクリック
3. メールで届いた9桁のパスコードを入力し「Sign in」をクリック

---

## 手順3 — AWS マネジメントコンソールに接続

1. サインイン後の画面で左メニュー「AWS account access」の **「Open AWS console (ap-northeast-1)」** をクリック
2. AWS マネジメントコンソールが表示されたら準備完了

---

## 手順4 — 権限の確認（マネジメントコンソールのみ）

Session1 以降を始める前に、この環境で必要な権限が付与されているかを確認します。コマンドは使わず、マネジメントコンソールだけで行います。

### 4-1. アカウントとリージョンを確認する

1. 画面右上のアカウントIDが表示されていることを確認する
2. リージョンが **アジアパシフィック（東京） ap-northeast-1** になっていることを確認する

### 4-2. 付与されている権限を確認する（IAM）

1. 検索バーに `IAM` と入力して選択
2. 左メニュー **「ユーザー」** → 自分のユーザー名をクリック
3. **「権限」** タブを開き、以下のポリシーが付与されていることを確認する
   - `AmazonDynamoDBFullAccess`
   - `AWSLambdaBasicExecutionRole`
   - `AmazonBedrockFullAccess`
   - `AmazonS3FullAccess`

### 4-3. アクセスキーを作成できるか確認する（Session4）

1. 同じユーザーの画面で **「セキュリティ認証情報」** タブを開く
2. **「アクセスキーを作成」** ボタンが押せることを確認する
3. 確認だけなら、作成せずに閉じて構いません。実際に作成した場合は、Session4 の後で削除してください。

### 4-4. Bedrock の呼び出しを確認する（Session3）

1. リージョンを **us-east-1（バージニア北部）** に切り替えて、Amazon Bedrock のコンソールを開く
2. **「Playground（プレイグラウンド）」** で推論プロファイル `global.anthropic.claude-sonnet-4-6` を選び、「Hello」などを送信する
3. 応答が返れば OK です。アクセス拒否やモデル未有効化のエラーが出た場合は、そのエラー文を控えてください。

### 4-5. Lambda の自動作成ロールにポリシーを追加できるか確認する

手順書では共通のロール（`lastname-firstname`）を使いますが、Lambda の作成時に自動で作られるロールにも権限を付けられるかを確認します。

1. 検索バーに `Lambda` と入力して選択 →「関数の作成」→「一から作成」
2. 関数名は `role-check-test`、ランタイムは **Python 3.12** に設定する
3. 「実行ロール」は **「基本的な Lambda のアクセス権限で新しいロールを作成」** のまま「関数の作成」をクリック
4. 作成後、「設定」→「アクセス権限」タブで実行ロール名（`role-check-test-role-xxxxxxxx` の形式）をクリックする
5. IAM のロール画面が開くので、「許可を追加」→「ポリシーをアタッチ」を選ぶ
6. 検索欄に `AmazonDynamoDBFullAccess` と入力してチェックし、「許可を追加」をクリックする
7. 追加できれば OK です。同様に `AmazonBedrockFullAccess` も追加できるか確認する
8. 確認が終わったら、Lambda の関数を削除する（関数の画面 →「アクション」→「削除」）。自動作成されたロールも IAM → ロールから削除してください

> ※ 権限の追加でエラーが出る場合は、そのエラー文を控えてください。
